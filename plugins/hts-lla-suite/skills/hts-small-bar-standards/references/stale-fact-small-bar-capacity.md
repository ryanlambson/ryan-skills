# Stale fact — WA small bar capacity 120 → 150

**Status:** STALE-SUPERSEDED (WARN)
**Verified:** 5 June 2026 against primary source.

| Field | Value |
|---|---|
| Old (stale) value | Small bar maximum 120 persons |
| Current value | **150 persons (patrons PLUS staff) at any one time** |
| Authority | *Liquor Control Act 1988* (WA), ss.41A/41B, as amended by the 2025 amendment package |
| Transition | Existing small bars apply via **Form 11** (application fee waived) to lift 120→150, subject to a safe-capacity assessment |
| Detection rule | WARN on any "120" in a small bar capacity context; suggest "150 (patrons + staff)" |
| Re-verify at | legislation.wa.gov.au |

check any trading-hours template that still recites the pre-2025 position.
